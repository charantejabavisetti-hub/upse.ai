# UPSC ZONE AI

A framework-free, browser-based UPSC study companion.

## What works

- Five-question Prelims-style mock test with answer explanations and a saved best score
- Personal study checklist with add, complete, and remove actions
- Weekly study-session tracker
- Revision notes and current-affairs prompts
- Adjustable daily study target
- Learner name and all progress persisted in the browser with `localStorage`

## Run it

Open `index.html` in a modern browser. For the most reliable local development experience, from this folder run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

No build step or third-party packages are required.
